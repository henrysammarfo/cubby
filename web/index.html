Cubby

Your face or fingerprint opens a Bitcoin Cash box, and the chain itself checks the approval.

This project started during BLAZE 2026. There is no earlier demo or earlier repository.

The test network coins have no value. A send needs about 20 000 test units in the box so the fee fits.

1. Connect a wallet with WizardConnect (optional)

This uses WizardConnect, not WalletConnect v2. Set your wallet to the same network as the switch above. You can also skip this and send coins to the box address yourself.

Scan this WizardConnect code in your wallet, or copy the connection link. Clicking the code also copies the link.

2. Create your phone lock

This uses the built in face or fingerprint check on this device. The lock is tied to this website address.

3. Put coins in the box

Send at least 20 000 units to the box address. Or paste the payment id after you send them.

4. Send them back with your face or fingerprint

My activity
